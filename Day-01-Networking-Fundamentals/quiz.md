# Day 1 Quiz - Networking Fundamentals

## OSI Model

### Q1. What does OSI stand for?

**Answer:**
Open Systems Interconnection Reference Model

---

### Q2. How many layers are there in the OSI Model?

**Answer:**
7 Layers

---

### Q3. Arrange the OSI layers from Layer 7 to Layer 1.

**Answer:**

1. Application
2. Presentation
3. Session
4. Transport
5. Network
6. Data Link
7. Physical

---

### Q4. Which OSI layer uses IP addresses?

**Answer:**
Network Layer

---

### Q5. Which OSI layer uses MAC addresses?

**Answer:**
Data Link Layer

---

## TCP/IP Model

### Q6. What does TCP/IP stand for?

**Answer:**
Transmission Control Protocol / Internet Protocol

---

### Q7. Which protocol is reliable: TCP or UDP?

**Answer:**
TCP

---

### Q8. What is the main difference between TCP and UDP?

**Answer:**
TCP is reliable but slower.
UDP is faster but does not guarantee delivery.

---

### Q9. Which protocol would you use for live video streaming?

**Answer:**
UDP

---

### Q10. Which protocol would you use for downloading a PDF?

**Answer:**
TCP

---

### Q11. What does connection-oriented mean in TCP?

**Answer:**
TCP establishes a connection using the three-way handshake before transferring data.

---

### Q12. What are the three steps of the TCP three-way handshake?

**Answer:**

1. SYN
2. SYN-ACK
3. ACK
