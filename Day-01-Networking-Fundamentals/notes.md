## OSI Model

1. Application
2. Presentation
3. Session
4. Transport
5. Network
6. Data Link
7. Physical

### Key Points

- IP Address → Network Layer
- MAC Address → Data Link Layer
- Router → Network Layer
- Switch → Data Link Layer

---

## TCP/IP Model

1. Application Layer
2. Transport Layer
3. Internet Layer
4. Network Access Layer

### Protocols

#### Application Layer

- HTTP
- HTTPS
- DNS
- FTP

#### Transport Layer

- TCP
- UDP

#### Internet Layer

- IP
- ICMP

#### Network Access Layer

- Ethernet
- Wi-Fi

---

## TCP vs UDP

### TCP

- Reliable
- Connection-Oriented
- Uses ACKs
- Three-Way Handshake

### UDP

- Faster
- Connectionless
- No Delivery Guarantee

---

## Three-Way Handshake

1. SYN
2. SYN-ACK
3. ACK
