## Key Takeaways

- A Hub broadcasts data to all connected devices.
- A Switch forwards frames using MAC addresses.
- A Router forwards packets using IP addresses.
- Switches provide better performance and security than hubs.
- Routers connect different networks and enable Internet communication.
