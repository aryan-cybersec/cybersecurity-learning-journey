# Day 2 Quiz - Hub, Switch & Router

## Questions

### Q1. What is a Hub?

**Answer:**
A hub is a networking device that broadcasts data to all connected devices.

---

### Q2. Which OSI layer does a Hub operate on?

**Answer:**
Physical Layer (Layer 1)

---

### Q3. How does a Hub send data?

**Answer:**
It broadcasts data to every connected device.

---

### Q4. What is a Switch?

**Answer:**
A switch forwards data only to the intended device using MAC addresses.

---

### Q5. Which OSI layer does a Switch operate on?

**Answer:**
Data Link Layer (Layer 2)

---

### Q6. What address does a Switch use?

**Answer:**
MAC Address

---

### Q7. What is a Router?

**Answer:**
A router connects different networks and forwards packets using IP addresses.

---

### Q8. Which OSI layer does a Router operate on?

**Answer:**
Network Layer (Layer 3)

---

### Q9. What address does a Router use?

**Answer:**
IP Address

---

### Q10. What is a CAM Table?

**Answer:**
A table used by switches to store learned MAC addresses.

---

### Q11. Why is a Switch more secure than a Hub?

**Answer:**
Because it sends data only to the destination device instead of broadcasting it.

---

### Q12. What happens when a Switch receives an unknown MAC address?

**Answer:**
It floods the frame and then learns the MAC address after receiving a reply.
